# Industrial Artificial Intelligence Projects

This repository contains projects completed as part of my Master's in **Industrial Artificial Intelligence**. The projects focus on solving real-world industrial and manufacturing problems using machine learning, deep learning, data analytics, and the **CRISP-DM** methodology where applicable.

---

# Repository Structure

## 📁 B5_RUL_Predictive_Maintenance

**Objective**

Estimate the Remaining Useful Life (RUL) of rolling element bearings using vibration sensor data from the FEMTO (PRONOSTIA) dataset.

**Project Focus**

- Predictive Maintenance
- Remaining Useful Life (RUL) Estimation
- Condition Monitoring

**Methodology**

- CRISP-DM
- Signal preprocessing
- Feature engineering
- PCA-based Health Indicator construction
- Convolutional Neural Networks (CNN)
- Support Vector Regression (SVR)
- Leave-One-Bearing-Out (LOBO) validation

---

## 📁 B5_OEE_Performance_Loss_Detection

**Objective**

Identify and analyze performance losses in an industrial production process using PLC data and Overall Equipment Effectiveness (OEE) metrics.

**Project Focus**

- OEE Analytics
- Performance Loss Detection
- Manufacturing Process Monitoring

**Methodology**

- CRISP-DM
- PLC data preprocessing
- Cycle segmentation
- Feature engineering
- Anomaly detection
- Isolation Forest
- Random Forest

---

## 📁 B5_Injection_Moulding_Quality
